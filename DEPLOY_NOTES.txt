BPSC NEXUS — AUTO CLASSIFICATION & CHAPTER DETECTION FIX

FILES IN THIS PATCH
- question_bank.py: extracts taxonomy metadata from JSON records and source_text; detects section as chapter; persists taxonomy nodes and source provenance for newly imported questions.
- miniapp.py: returns detected taxonomy in preview, reports unique chapter names and field mappings, and accepts 64 MB uploads.
- index.html: shows the detected hierarchy and auto-mapping in Question Import Studio before import; updates upload limit text and validation.
- 001_import_classification_schema.sql: additive, idempotent PostgreSQL schema migration for taxonomy and provenance tables/columns.

AUTO-DETECTION RULES
- target exam: explicit target_exam/exam_name when present; otherwise BPSC when source_pdf identifies a BPSC import file.
- subject: explicit subject field or `Subject:` in source_text.
- category: explicit category field; defaults to General Science for Physics, Chemistry and Biology.
- chapter: explicit chapter field, otherwise `section`, otherwise `Chapter:` in source_text.
- topic/subtopic: only populated when explicitly present.
- `Source exam:` is retained as source provenance. It is NOT treated as the target exam.
- `Source page:` is retained in source metadata and question_sources.
- Existing question IDs, quiz links, attempts and question text are not rewritten. Duplicate question hashes continue to be skipped as before.

DEPLOY STEPS
1. Back up the current deployed files and PostgreSQL database.
2. Replace deployed question_bank.py, miniapp.py and index.html with these exact files.
3. Run 001_import_classification_schema.sql against the same PostgreSQL database. It is additive and idempotent. The application startup schema routine also contains the same additions.
4. Restart/redeploy the service.
5. Open Admin → Question Import Studio, select the destination subject, upload a JSON file, and click Preview extraction.
6. Verify detected Exam / Subject / Category / Chapter values and the unique chapter count before Confirm & Import.
7. Test with a small file first. Do not re-import the same questions expecting duplicates to be added; the existing question_hash uniqueness behavior is preserved.
