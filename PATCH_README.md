# BPSC NEXUS final package

This is a clean, self-contained native Telegram quiz bot package. It is not a partial patch. It includes the bot runtime, question bank, group quiz engine, leaderboard module, dependency file, Termux runner and deployment configuration.

The existing Neon PostgreSQL database is retained by configuring the same `DATABASE_URL`. No database reset or destructive data operation is included.

See `README.md` and `LOCAL_SETUP.md` before deployment.
