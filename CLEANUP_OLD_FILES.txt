This final package is a clean native Telegram bot distribution. It intentionally does not include legacy Mini App, payment, membership-pass, web dashboard, or static frontend files.

When replacing an older project checkout, back it up first. Deploy this package as a separate clean project or replace the old application code only after confirming that the hosting start command points to `python bot.py` and the existing DATABASE_URL is retained.

Do not drop or truncate the existing Neon database. This package performs additive schema setup and does not execute the previously discussed data reset.
